# Sources that fail from a GitHub Actions runner but not from a laptop.
#
# The feed-liveness workflow compares each run's failures against this list
# and reports only the ones that aren't on it. That is the whole point: a
# count-based threshold had to be set so loose (22 of 60) that real rot could
# hide under it, while this lets the check react to a single new failure
# among the sources CI can actually reach.
#
# One name per line, matching the name column in the report exactly.
# Blank lines and # comments are ignored.
#
# A leading "~" means intermittent: expected to fail *sometimes*. The
# workflow never suggests pruning those, because a run where one of them
# passes is normal rather than evidence it recovered. Everything without a
# "~" is expected to fail every time, so if one of those passes the workflow
# says so — that's what keeps this list from rotting into permanent excuses.
# Measured 2026-08-21 across four dispatch runs (32532904159, 32533626897,
# 32533974955, 32534721347).
